과학송 경연대회 심사 시스템 설치 안내

채점관이 휴대폰으로 채점하면 점수가 구글 시트에 모이고, 학년별 1등과 2등이 자동으로 정해집니다. 팀과 팀원, 곡 제목, 발표 순서는 웹앱 안에서 넣고 고칩니다.

설치 (한 번만, 10분쯤)

1. 구글 시트와 Apps Script 만들기

  1. 새 구글 스프레드시트를 만들고 이름을 "과학송 심사"로 붙입니다.
  2. 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
  3. 처음 들어 있는 코드를 모두 지우고 Judge.gs의 내용을 통째로 붙여 넣은 뒤 저장합니다.
  4. 위쪽 함수 목록에서 setup을 고르고 실행을 누릅니다. 권한을 묻는 창이 뜨면 허용합니다.

시트에 설정, 순서표, 심사기록 탭이 생깁니다. 설정 탭에서 관리자 코드(8자리)를 확인해 적어 둡니다.

엔트리 폼의 Code.gs가 있는 프로젝트에는 넣지 마세요. 두 코드의 기능이 겹쳐 엔트리 폼이 멈춥니다. 반드시 새 시트의 새 프로젝트로 만듭니다.

2. 웹 앱으로 배포하기

  1. Apps Script 오른쪽 위에서 배포 → 새 배포를 누르고 유형으로 웹 앱을 고릅니다.
  2. 실행 계정은 나, 액세스 권한은 모든 사용자로 둡니다.
  3. 배포한 뒤 나오는 웹 앱 URL(/exec로 끝남)을 복사합니다.

3. 웹앱에 주소 넣고 올리기

  1. judge.html을 메모장으로 열어 const API_URL = '';를 찾습니다.
  2. 따옴표 사이에 복사한 주소를 붙여 넣고 저장합니다.
  3. 엔트리 폼이 있는 GitHub 저장소에 judge.html을 올립니다.
누가주소들어갈 때
채점관(내 페이지 주소)/judge.html이름과 심사 코드
진행 교사 (팀 편집)(내 페이지 주소)/judge.html#manage관리자 코드
진행 교사 (결과와 발표)(내 페이지 주소)/judge.html#result관리자 코드

4. 팀 넣기

팀 편집 화면에서 학년을 고르고 팀을 넣습니다.

  • 팀 추가를 눌러 곡 제목과 팀원 이름을 적습니다. 팀원이 세 명 이상이면 팀원 칸 추가를 누릅니다.
  • 여러 팀 한꺼번에 넣기에는 엑셀이나 한글 표에서 복사한 내용을 그대로 붙일 수 있습니다. 한 줄이 한 팀입니다.
  • 발표 순서는 ↑ ↓ 단추로 옮기거나 순서 무작위로 섞기로 추첨합니다.
  • 대회 이름과 심사 코드도 이 화면에서 바꿉니다.
  • 고친 뒤에는 화면 아래의 저장을 눌러야 반영됩니다.

5. 시험해 보기

두 사람 이름으로 한두 팀을 채점해 보고 결과 화면과 발표 화면을 확인합니다. 시험 점수는 구글 시트 심사기록 탭에서 머리글만 남기고 줄을 지우면 없어집니다.

당일 쓰는 법

채점관

  • 이름은 매번 똑같이 써야 앞서 낸 점수를 고칠 수 있습니다.
  • 항목마다 수준을 누르면 점수가 들어가고, 막대나 −, + 단추로 구간 안에서 조정합니다.
  • 점수 제출을 누르면 다음 팀으로 넘어갑니다. 제출 전 점수는 기기에 남아 있어 화면을 닫아도 사라지지 않습니다.

진행 교사

  • 결과 화면에서 학년별 순위, 항목별 평균, 채점 인원, 채점관별 총점을 봅니다. 줄을 누르면 채점관별 점수와 한줄평이 펼쳐집니다.
  • 채점표 인쇄는 학년마다 A4 한 쪽으로 나옵니다.
  • 발표 화면은 학년별로 2등, 1등 순으로 공개합니다. 화면을 누르거나 → 키로 넘기고, ← 키로 되돌리고, Esc로 닫습니다.

순위 규칙

  • 팀 점수는 그 팀을 채점한 사람들의 총점 평균입니다. 채점관 수는 몇 명이든 되고 팀마다 달라도 됩니다.
  • 총점 평균이 같으면 과학 개념 정확성 평균, 그다음 창의성과 독창성 평균이 높은 팀이 앞섭니다.
  • 그래도 같으면 공동 순위입니다. 공동 1등이 나오면 2등은 비게 되고 결과 화면에 알림이 뜹니다.
  • 다른 팀보다 채점 인원이 적은 팀은 결과 화면에 따로 표시됩니다.

알아 둘 점

  • 채점이 시작된 뒤에도 발표 순서, 곡 제목, 팀원 이름은 바꿀 수 있습니다. 점수는 팀에 그대로 붙어 있습니다.
  • 점수가 들어온 팀을 지우면 그 점수는 집계에서 빠집니다. 지울 때 한 번 더 확인합니다.
  • 채점관은 처음 들어올 때 팀 목록을 받습니다. 채점 도중 팀을 고쳤다면 채점관에게 화면을 새로 고치라고 알려 주세요.
  • 관리자 코드는 구글 시트 설정 탭에서만 바꿀 수 있습니다.
  • Judge.gs를 고친 뒤에는 배포 → 배포 관리 → 수정 → 버전: 새 버전으로 다시 배포해야 반영됩니다. 주소는 그대로입니다.
  • "심사 서버에 연결하지 못했습니다"가 뜨면 배포의 액세스 권한이 모든 사용자인지, 주소가 /exec로 끝나는지 확인합니다.
  • 채점 기준 문구나 배점을 바꾸려면 judge.html과 Judge.gs에 든 RUBRIC 표를 똑같이 고쳐야 합니다.
